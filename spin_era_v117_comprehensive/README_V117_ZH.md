检查点也核对核心规则文件指纹。同名候选中代码/数据已变时不能直接续跑，应保留并使用匹配的原包。

潜能兑现目标是在良好培养情景下接近PA±10，同时保持普通精英与不利生涯的差异；PA是窄区间估计，不保证每次兑现。平均峰龄目标为26—31岁，身体衰退降低实际技术表现，学会经验单独保留。

详细比赛用于需要逐板技术叙述的重点比赛；轻量比赛用于结果与趋势，不能据聚合结果编造逐板事实。时间线截止2028奥运会，未来赛历为模拟模板而非认证史历。

削球/颗粒的轻量正式计分仍有显著模式偏差，World默认拒绝此类summary赛事；赛前选择full，或显式开启未校准实验。练习轻量可用，无隐藏详细引擎回退。完整限制见技术报告。

当前随目录保留的`README_ZH.md`、`OPENING_ZH.md`与HGR报告属于V1.1.6基线，不能替代本版操作说明。

在Python 3.11+环境，从总包根目录执行：

```bash
python examples/start_v117.py --output /tmp/spin-v117-start --demo
python run_v117_qa.py --output /tmp/spin-v117-qa
```
