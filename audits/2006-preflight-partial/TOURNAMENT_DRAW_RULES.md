# 签表与资格边界

原V1.18支持BO3/BO5/BO7、小组表与显式签位替换，但旧run_event只是洗牌并跑完整场。正式同国回避、种子保护、轮空资格、全区签位继承及胜后暂停并未全部实现。青年入口年龄预检可被run_group/外部结算绕过，需统一资格服务；史实cutoff和协会名额不足时应阻断认证。

本次最小draw_identity补丁仅修复“新增球员已在签表中仍被替换进去，产生重复球员”的确定错误；50个正常输入种子与原函数相同。它不等于实现完整抽签系统，也不认证旧开罗第15资格组或64强原轮空位的合法性。

已锁定旧世界线结果保留；未知原签位标HYPOTHETICAL或UNVERIFIED。下一场只能展示确认的实际签位与持久化对手卡，不得自动开始正式比赛。2007正式比赛本轮零场。
