# 下一批材料如何上传

限制发生在ZIP传入执行环境之前，并非Python不会解压。请在自己的电脑上右键该大ZIP选择“全部解压”（或用7-Zip/系统归档工具）。

先上传两份根目录小文件：

1. CODEX_MASTER_PROMPT.md
2. SOURCE_MANIFEST.json

建议先只解压最外层。随后上传里面的2005年终档案、2006全年及首版开罗决赛权威包；内层ZIP若已小于32MiB就原样上传，不必再次解压重打包，这样能直接核对它在SOURCE_MANIFEST中的ZIP哈希。每个附件小于32MiB，建议控制在30MB以内；仍超限就把年度包继续解压，按赛季/站点分组压缩，不改原文件内容。源ZIP不删，重打包只用于传输，原始文件SHA依旧能对账。

本环境已有此前V1.18和原2004完整包，暂时不必重复传；先用SOURCE_MANIFEST确认是不是同一批字节。只传清单不能替代那些尚无本地副本的历史文件。

也可把原大ZIP上传此前GitHub仓库后给出文件路径；邮箱地址不能替代文件链接。
