# 叙事与机械事实边界

本轮没有生成或改写2005—2006剧情。收到原始编年资料后，再按事件ID、日期、人物和关系时间线整合。

事实层MatchFacts只读取已核验比分、参与者、实际动作、来球、到位、随机判定与局间调整；叙事层无数值写权限。逐板有证据标LOG_GROUNDED；酒店、触觉、对话、心理等合理文学补写标NARRATIVE_INFERENCE，不伪装采访或史料。summary只能给聚合趋势，不能指认某分未生成的反手抢拉。

提供每局简短、关键段落、中长篇三种深度，默认中等；球风偏好、当场选择、实际成功、性格表达分别描述。人物记忆和关系用独立时间线，不能因社交或冠军直接加CA。新包未读前不能拼凑所谓“完整三年编年史”。
