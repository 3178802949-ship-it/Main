# V1.1.7 下载与新聊天使用

下载以下两个文件，即可准备新的聊天模拟：

1. [完整总包ZIP](Spin_Era_V1_1_7_Integrated_Candidate.zip)。在GitHub文件页点击 **Download raw file** 保存到本地。
2. [中文开幕文档](OPENING_V117_ZH.md)。可下载或复制全文。

将总包与开幕文档作为附件交给新聊天。续玩时另附最近的完整World检查点；
需要继续逐板叙述时，也附该比赛匹配的外置全文日志。
总包已有`examples/v117_demo_output`：完整18岁测试卡、起始存档、一个月体验存档与摘要。

四个独立模块用于检查和开发：

- [Game](Spin_Era_V1_1_7_Game.zip)
- [Card](Spin_Era_V1_1_7_Card.zip)
- [Training](Spin_Era_V1_1_7_Training.zip)
- [Area](Spin_Era_V1_1_7_Area.zip)

阅读[版本说明](README_V117_ZH.md)、[设计说明](V117_DESIGN_ZH.md)与
[实际技术报告](V117_TECHNICAL_REPORT_ZH.md)了解规则、实测条件与未通过项。
每个ZIP有对应`.sha256`文件；[封包验证](V117_PACKAGING_VERIFICATION.json)记录干净解压与实际检查。

本包为测试候选。模拟日期、样本排名和合成球员实验不代表现实历史认证；
轻量统计只能支持结果与趋势。运行结算需要能够执行Python的环境，文学叙述不代替函数调用。
