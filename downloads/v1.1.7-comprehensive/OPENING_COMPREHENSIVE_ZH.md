## 球风与人物档案

公开卡的`style_profile`描述偏好手段；后台`personality_profile`只供叙述参考。能力与偏好必须分别解释：擅长、偏爱、当前可行、实际选择是四个不同判断。选手可以偏爱某项，但仍因来球、到位、体能和阅读选择另一项。

比赛只调用当前表现、明确器材/战术和受限风格先验。人格不进入Game，不给稳定、失误、冠军或成长加成。不要把内向写成稳定、外向写成冒险、落败写成脆弱，也不要根据赢球倒推真实人格。

公开资料线索须保留source日期、出处和可信范围。`SIMULATED_NARRATIVE_DEFAULT`等标记表示创作设定，不是现实人格结论。没有核实访谈时，不编造采访语句、私人经历或私下性格。可以写明确标为虚构的氛围或互动，但不能将其混入真实比赛事实和人物公开资料。

叙述使用`Card.v118.narrative_view`按当前世界年份/日期过滤后的视图。未来访谈、论文可以作为时代外设计参考，不能成为早年角色已知的事实。人物资料库保存较晚来源，不等于早期角色当时已经具有某个被证实的标签。公开卡使用`public_view`，不要直接泄露后台完整人格或潜在发展参数。

## 结算与叙述顺序

1. 读取当前有效卡、学会技术、PA区间、身体支持上界、疲劳、健康、资源、排名和时钟。
2. 在结算前选择summary或full，保留唯一事件ID与seed。不能先跑两种算法再挑有利赛果。
3. 通过World结算比赛、训练、投资与健康；正式赛事由完整签表结束后结算积分、冠军和发展证据。不得再手动重复调用底层模块领收益。
4. 根据真实返回的log或receipt生成叙述，记录引用证据范围。文学层与事实层分开。
5. 深度一致性检查通过后保存完整World检查点；逐板全文按需外置并匹配哈希。续玩时同时附需要叙述的全文。

summary只有比分、聚合动作/回合/负荷等估计，只能讲赛果和大致趋势；不能写“第几局第几分的一板线路”“某次心理动摇导致失误”。full也只能根据真实shots叙述，心理动机仍不是日志事实。详细全文丢失后，即使还有精简收据，也退回结果和趋势叙述。

叙述应适度变化：可轮换赛果、节奏、技术分布、体能和时代背景的切入点，但不得为了避免重复而改变事实。保留同seed可复现和有界的叙述历史。人物线索最多影响表达方式，不创造场上行为。

## 训练、PA与奖励

每月两阶段，每阶段两种技术大类和一项体能；可在大类内选两个不同子项专精并承担额外负荷，其他项目仍有一般训练和卓越成长机会。所有XP、许可、直接成长都服从时间、疲劳、年龄、身体支持和技术上限。

冠军、强对手比赛和训练突破提供有出处、有限次数与期限的专项机会，不是夺冠就送固定技术点。重复事件、同一证据重复使用和弱场刷高级机会应被程序拒绝。身体能力下降后，应同时展示学会技术与实际可表现技术，不能以技术记忆抵消P衰退。

PA口径是生涯潜能评估，默认窄带中心±3，不是统计置信区间。普通自然老化或低谷不自动减少PA，证据充分的成长可小幅提高估值。重大伤病可能持久降低P上限及部分潜能，轻伤主要体现临时身体损失和康复期。当前年龄身体结构上界另列，稳定PA不承诺老年仍可练到该CA。

## 实际启动与续玩

先运行`python verify_package.py`，读取`reports/comprehensive/qa/COMPREHENSIVE_QA.json`和`docs/COMPREHENSIVE_QA_ZH.md`。使用公开门面：

```python
from pathlib import Path
from simulator import WorldSession, Card, Game, Training, Area
w = WorldSession.load(Path('examples/comprehensive_demo_output/START_WORLD_COMPREHENSIVE.json').read_text(encoding='utf-8'))
assert w.consistency_check(deep=True)['valid']
print(w.card(w.data['main_player_id']))
```

此START是尚未行动的2006-02-01起点。若用户未要求立即推进，先展示公开卡与选项，等待训练/比赛选择。`DEMO_WORLD_COMPREHENSIVE.json`为另存的示范一月，不能当成用户已经完成的行为。创建独立起点可执行`python examples/start_comprehensive.py --output saves/new_career`。

每次操作后深检并保存`w.dump()`；不要只保存角色卡和文字总结。详细比赛若有外置artifacts，按导出清单一同保留；载入后用`attach_artifact`核验再叙述逐板。后台人格由`w.narrative_profile(pid)`读取，可用作明确虚构的表达参考，不默认公开全部后台字段。

如需原创球员，应先确定起始日期、年龄、当前43/P6、PA窄带、手别/器材、球风与用户自定性格，再通过Card校验并创建World。若从测试卡复制，务必更换player_id/preset_id、姓名/原型/来源、出生年/快照日期；清除继承的`style_profile`、`personality_profile`、`career117_profile`、`career118_profile`后重建。未经确认的高PA/国训资源属于场景设定，不能暗中赠送。不要把一个现有World内的卡直接编辑成另一人。

冠军窗口的合法奖励倍率区间为1.1125—1.25，常规突破为1.09—1.20，均只在资格通过并获准时生效；同项重叠取最大，不相乘。完整触发、专项使用证据和12个月预算见`docs/V118_GROWTH_ZH.md`，结算以receipt为准。
