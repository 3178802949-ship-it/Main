# 《旋球年代》V1.1.7 综合版｜下载与交接

**一般只需下载两个文件：**

1. [Spin_Era_V1_1_7_Comprehensive.zip](Spin_Era_V1_1_7_Comprehensive.zip)：完整工程、四模块、完整开局卡/存档、测试与证据。
2. [OPENING_COMPREHENSIVE_ZH.md](OPENING_COMPREHENSIVE_ZH.md)：交给新聊天的开幕说明。

GitHub网页版：打开ZIP文件页面，点击右上角 **Download raw file / 下载原始文件**（下载箭头）。ZIP无法在线预览是正常情况。Markdown文档也可用Raw/下载按钮保存。不要把网页另存为HTML来代替ZIP。

把总包ZIP和开幕文档一起作为附件上传新聊天，然后说：

> 按开幕文档校验本包并恢复examples/comprehensive_demo_output/START_WORLD_COMPREHENSIVE.json，先展示公开卡与可行动作，不提前推进时间。实际调用程序结算后再叙述；无法执行Python时请明确说明。

默认起点是2006年2月1日的马龙式18岁测试卡。原创球员可另行建卡；不要把演示一月结果当成用户已完成的操作。

四个独立分包供模块使用与检查；总包已经包含它们，普通玩家不用再逐个上传。`*.zip.sha256`提供文件校验；`COMPREHENSIVE_PACKAGING_VERIFICATION.json`记录干净解压检查。

实际结果：351项行为测试；100条条件成长曲线；128场风格对照；96份叙述审计。良好培养48/48峰值在PA±10，但有限资源场景不保证达标，冠军窗口也未证实会提高最终峰值。削球/颗粒的正式summary仍受未校准保护。3篇作者摘要已读，体育训练原文及真实人物采访未核验，人格明确采用模拟设定。

详见 [README_COMPREHENSIVE_ZH.md](README_COMPREHENSIVE_ZH.md)、[COMPREHENSIVE_QA_ZH.md](COMPREHENSIVE_QA_ZH.md) 和 [V118_AUDIT_ZH.md](V118_AUDIT_ZH.md)。公开版本为V1.1.7综合版，内部v118文件名仅标记本轮增量实现。
