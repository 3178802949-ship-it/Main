# V1.1.7 综合版 比赛偏好与逻辑核查

本版增加一个小的动作选择先验。它回答“更喜欢怎样打”，不回答“实际有多强”。
入口为 `from Game import v118 as Game`，规则ID为 `V1.1.7-COMPREHENSIVE-1`。
旧比赛源码、旧Game入口、旧比赛数据均保持原字节。

## 权威边界

`Game.play_match(cards, seed, match_id, ..., detail_level='summary'或'full')`
接受当前有效43技术子值、P6、G9、CA、打法/手/胶皮/战术和风格轴。
`match_card`会投射必要字段，PA、XP、冠军历史、学习天赋、人格、档案来源原文不会进入比赛进程。
输入摘要也只绑定实际投射字段。更改后台人物性格不能改变胜负或输入摘要。

公开边界继续提供 `verify_log`、`compact_log`、`review_event`。详细曝光来自实际接触；
聚合曝光是估计，含发球但不把未接到球奖励成技术接触。详细全文与精简收据的证据层级继续区分。

## 风格与具体战术的关系

旧V1.1.7合法动作池、技术适配、实际到位、胶皮和当下战术先计算原概率。
V1.1.7 综合版只在已存在的合法候选上施加0.90—1.10倍的小权重，再归一化。
不新增候选，不改技术质量、日常状态、实际G、CA、身体、失误、学习或直接得分概率。
偏好一个较弱的正手，不会获得额外正手能力；不利到位下的技术适配惩罚仍然存在。
偏好未声明或各轴均为0.5时，直接返回旧概率对象，不消耗额外随机数。

| 轴 | 本版实际影响 |
| --- | --- |
| 正手/反手使用 | 既有合法动作的实际击球侧权重 |
| 台内控制 | 真实短球情境及合法短球处理的轻微权重 |
| 前三板 | 详细模式真实发接发/第三板情境中的主动处理权重；聚合长球近似基本不触发 |
| 上旋偏好 | 反胶/未知面既有主动上旋家族偏好，不替代颗粒自身转换规则 |
| 下旋控制 | 反胶/未知面的既有搓削控制偏好，不承诺颗粒回球必为下旋 |
| 主动/反击 | 既有主动、反击/挡等家族权重 |
| 风险 | 仅到位良好时对主动选择的小权重；受限/糟糕到位严格不增加此权重 |
| 相持/远台/旋转变化 | 目前仅观察与叙述，未新增站位或旋转奖励 |

这不是强制战术，也不是给冠军或姓名的独立加成。既有技战术阅读与局间调整仍决定当下选择。
人格档案是叙述资料，不参与心理检定或比赛能力。

0.90—1.10是明确的游戏设计参数，不是乒乓球论文测得的效应量。
本轮网络原站访问受限，不能把检索线索或作者Github说明冒充已阅读全文的期刊研究；
实际可读范围与来源由 `docs/V118_RESEARCH_ZH.md` 分级说明。

## 隔离与追踪

每场在新Python进程里执行，临时挂接两个旧引擎共同的纯候选函数，结束后恢复。
详细引擎和真正聚合引擎继续分开，没有隐藏的详细计算回退。
`style_preference_audit`记录作用轴、仅观察轴、加权调用数、乘数上下界、最大候选概率变化，
并明确 `personality_used=False`。该有界汇总随compact收据保留。
旧引擎的实际模型标识不伪装成新数学，日志的规则ID和叠加层指纹另行记录。

## 实验与限制

定向检查覆盖中立full/summary逐分重放、人格对照、输入不变、两手/五种胶皮合法性、
到位限制、弱偏好侧不变强、重复执行、曝光/负荷和收据。旧完整比赛的对照不只比较最终赢家。
本次14项针对性检查通过，实际输出见 `reports/comprehensive/game/GAME_TESTS.txt`，
机器摘要见同目录 `GAME_QA.json`。

`examples/benchmark_style_v118.py`预声明四种合成环境、每组连续种子，比较中立与偏好声明、
详细与聚合两模式。它测选择敏感性和合法接触，不拟合历史胜率，也不保证偏好使人更容易赢。
按原预声明种子重新执行128场；每次输入/源码指纹都检查前后相同，
最终综合版证据见 `reports/comprehensive/game/style_benchmark/GAME_STYLE_BENCHMARK.json`。
原开发报告保留在旧目录，不代替最终版本的源码绑定。

原V1.1.7 LIGHT-4留出中，施拉格/朱世赫组详细33:31、聚合14:50，相差29.69个百分点。
这项专业打法聚合分布偏差没有在本补丁修复，也没有因新增风格而重新认证。
削球/颗粒的正式summary仍必须经过World的显式实验保护；不因新增人物风格就宣称其排名分布已校准。
聚合模型仍缺少完整发接发、台内与逐板位置状态；风格标签不能把这些未知过程补写成事实。
