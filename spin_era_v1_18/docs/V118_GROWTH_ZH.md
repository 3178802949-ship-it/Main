# V1.1.7 综合版｜PA、身体衰退与训练奖励复核

本轮冻结实现位于`runtime/career_v118.py`与`Training/v118.py`，文件名中的`v118`仅是开发内部路径。公开版本为V1.1.7综合版；原V1.1.7源码、数值档案和旧存档没有重写。新状态使用`V1.1.7-COMPREHENSIVE-1`、`V1.1.7-COMPREHENSIVE-TRAINING-1`以及`career_v118`内部发展档案，拒绝把旧准备卡或旧训练状态改标签后当作已迁移。

## 潜能与剩余能力采用两种口径

PA表示**生涯潜能估值**，不是当前年龄还可以练回的能力。普通衰老、训练不足、暂时低谷和轻伤都不会自动下调PA；有持续成长证据时，峰期附近可以小幅提高估值，普通年度最多2点。估值带仍为中心±3并在0—200边界截断；这是一项稳定性设计，不是统计置信区间。

首次建立30岁以上人物也不再把PA压成当前CA附近。身体实际下降继续通过P6、年龄累积损失和专项身体支持上限影响比赛：`children`为可表现技术，`learned_children`为学会经验，CA按当下可表现值计算。PA不能为比赛加G，也不能裁剪当前CA。

`performance_card()`另外提供`remaining_body_envelope`和`remaining_body_ceiling_P6`：它们是假设达到当前年龄身体上限及其可支持专项上限时的结构包络，**不保证剩余生涯有足够时间练到**，更不是新的PA。40岁仍保有较高生涯PA，不表示能重新拥有青年身体。

新开年长卡会先按峰后年龄为未来训练空间设置衰退先验，保护已观测P6及技术原值，避免新开40岁角色却把全部身体上限当作尚未衰老。该先验不是重新演算真实人物过去几十年的历史。

## 伤病的临时影响与永久影响

伤病等级是游戏中的影响尺度，不是医学诊断或现实运动员的预后结论。

| 等级 | 身体与康复 | PA与潜在档案 |
| --- | --- | --- |
| 1—2 | 暂时P损失、有限康复时间，恢复有明确余额 | 不降低Pmax、专项终身上限或PA |
| 3—5 | 持久Pmax损失与少量临时损失分开记录 | 仅在永久身体/专项结构包络确实下降时，PA和潜在目标同步小幅下调，单次0—3点 |

部分重大伤病的结构损失不足以改变整数PA，可能出现PA不变；身体与康复代价仍存在。永久损伤不因跨年、休整或再获冠军自动抹除。公开估值以后若仍处于被低估阶段，可以在**降低后的潜在目标内**逐步上升，不能暗中把受伤前目标恢复。

每次伤病保留事件ID、身体变化、Pmax前后、包络变化、PA前后与潜在目标前后；实际PA下降另记入估值事件。普通衰老则只影响实际能力及剩余结构包络。

## 长期培养实际结果

预声明种子、环境、事件类型及源码指纹均保存在各报告对应的`.plan.json`中。实验运行前后核对源码一致，没有根据某名球员的胜负或峰值反复挑种子。

共执行100条条件曲线：48条良好培养留出、12条同种子无机会窗口对照、20条五先验×环境矩阵、12条投入/过载压力和8条轻重伤分离对照。无窗口对照与48条中的12条配对，**不能把配对一方再算成额外独立样本**。这里只有六个固定起点，不能推断整个世界的人口稀有率。

| 检查 | 结果 |
| --- | --- |
| 良好培养峰值接近当时公开PA±10 | 48/48，最大差4 |
| 良好培养平均首次峰龄 | 26.92岁；没有31岁后的首次峰值 |
| 38岁平均较峰值CA下降 | 16.52 |
| 无永久损伤的92条曲线出现PA下降 | 0条 |
| 永久损伤的8条曲线中PA下降 | 均有对应伤病与结构损失证据 |
| 估值带宽度 | 全部不超过6 |

良好条件为长期国家级训练质量、90%可训练/恢复时间、轮转全部大类、无伤病，赛事机会全部标为SYNTHETIC。它是可达性上界，不是默认World资源和赛程，也不是现实运动员实际未来。完整职业世界仍要承担比赛旅行、时间、预算、选项和伤病。

普通精英没有被整体抬成历史级。PA165起点在理想样本峰值163—165，PA181起点为178—181；历史级试验卡为192—196。

高潜马龙式起点在两条混合投入压力样本中峰值190、191；低投入或过载并伴固定测试伤病的样本约177。投入、安排与健康仍决定兑现程度。

轻重伤分离对照中，18岁高潜卡在24岁接受一次合成全身体等级5损伤后，PA结构损失3点，峰值191—192；同种子的等级2临时损伤不削减终身PA/上限，峰值194。这个受控极端情境不是现实某种伤病的预测。

## 奖励、预算与重复结算

本轮保留已验证的普通训练XP基准、PA温和倍率、年龄/疲劳效率、许可成本及身体衰退系数。一般训练仍可卓越；专精只重新分配本类训练关注并增加负荷，不增加额外掷骰。

高质量冠军或复盘证据可以打开有限期、限专项的XP窗口。可获窗口的证据质量乘积至少为0.45；冠军窗口最长2个月、倍率1.1125—1.25；普通复盘/营地窗口最长3个月、倍率1.09—1.20。滚动12个月最多2个冠军窗口与6个普通窗口，同一专项同时存在多个窗口时取最高倍率，不相乘。它们不直接增加G、P、PA或永久技术点。

相同事件ID或相同证据不能重复领取。休息和零训练时间不能把旧XP银行兑换为新技术点。XP、许可、身体XP分别有授予、支出和过期账目，长期保存保留去重身份及有界回执。

12个同种子理想培养配对中，有/无机会窗口的年度CA及最终峰值均相同：专项窗口的短期XP增益通过定向测试，但本组达到结构上限后没有额外整数CA收益。不能将其宣传为“夺冠一定增加峰值”。实际World还要求强对手、近水平胜场和真实技术曝光；弱小四人赛不能刷取精英发展资格。

## 验证与未解决边界

20项成长测试覆盖：自然衰老和坏年不降PA、轻伤恢复且不降上限、重伤持久目标、年长开局口径、带宽、年增上限、奖励局部性/时效性/去重、XP账目、零时间、年龄疲劳、日志上限与原样续接。

仍保留以下限制，没有为抹平它们临时修改参数：

- 低潜能理想卡可能22—23岁较早触顶，并有平均约7年的整数CA平台；不能把平台结束年龄冒充首次峰龄。
- 五先验环境矩阵仍有一条俱乐部环境、后期突破先验的高潜卡在32岁首次达到CA187；平均目标通过不代表每个人都在31岁前达到最高整数CA。
- 150专项硬顶及包络回推仍压缩历史级卡在顶端的个性，需要扩大真实打法与参数分布验证。
- 冠军窗口在已近上限、或奖励到已完善专项时会变得不明显；用户界面应显示实际XP/窗口收益，不能用叙述补造能力点。
- 本轮没有完成原始乒乓球论文核验，不能声称论文已支持这些具体年龄、生理、伤病或奖励参数。PA、CA、±3估值带与各项系数均是游戏设计假设，不是运动科学定律；可读取资料及尚未核验边界见`V118_RESEARCH_ZH.md`。

最终机器证据入口为`reports/comprehensive/growth/GROWTH_EVIDENCE_INDEX.json`。全部曲线、配对关系、当前身体包络和伤病证据均可追踪；`reports/v118`开发阶段结果与旧V1.1.7报告只作历史基线，不能和本次重放重复计算为独立样本。
