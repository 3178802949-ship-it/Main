# V1.1.7 综合版｜观察用打法倾向与后台叙述档案

本层回答球员倾向于怎样组织比赛。43技术、P6和临场状态回答能做到什么；Game的合法动作与当下决策回答这一板实际做什么。偏好词不表示技术强弱，也不保送相应动作。人物性格只供叙述参考，不参与胜负、训练或冠军奖励。

## 可观察风格

`Card.v118.prepare(card)`保留原数值，附加`style_profile`。12轴均在0—1：

| 轴 | 观察含义 |
| --- | --- |
| forehand_use / backhand_use | 更愿意由哪一侧组织来回，不是正反手能力分数 |
| short_game | 对台内控制和短球组织的偏好 |
| first_three | 希望在发接发与起板阶段争先 |
| rally | 愿意通过连续衔接寻找机会 |
| away_table | 对离台周旋与纵深空间的偏好 |
| topspin_preference | 希望进入上旋连续的倾向 |
| backspin_control | 希望用下旋控制与削搓组织的倾向 |
| spin_variation | 对旋转变化的偏好 |
| initiative | 主动改变来回的意愿 |
| counterattack | 控制、等待后寻找反击窗口的偏好 |
| risk | 愿意承担执行风险的倾向 |

第三方看到一个大类、2—4个细标签与组织方式描述，例如台内组织、反手组织、上旋衔接、择机加速。轴主要由同年度预设中的`tendencies`、`role`、`style`映射；不读取CA、PA、冠军名单或未来技术描述。映射系数属于透明的游戏设计估计，不是论文拟合结果，也不是已认证现实球员风格。

轴可以重叠。相持偏好高并不意味着不能抢攻；正手组织偏好高并不意味反手能力弱。Game可在现有合法候选里使用小幅先验，仍受当下情境、能力、到位与风险限制；实际启用的轴以Game报告为准，其他轴只供观察，不要宣称全部12轴均已生效。

当前Game将`rally`、`away_table`、`spin_variation`保留为观察轴；不把它们宣传为已执行的战术修正。`first_three`只在真实发接发/前三板情境启用，轻量长球相持代表情境通常不启用。其他已激活轴只能微调现有合法候选的概率，不修改质量、身体或失误公式；风险轴在受限、差到位状态也不能绕过安全约束。

104位原型、370张年度快照均有覆盖。偏好来自原档案的模型评估，精确年度字段不等于当时经过实证测量；避免把回溯设计估值写成青年选手必然走向其后来冠军生涯。

原档案继承的原型有同质化现象，因此另给14位精英建立显式`CURATED_GAME_DESIGN_PRIOR`：马龙、樊振东、马琳、王皓、许昕、王励勤、张继科、瓦尔德内尔、波尔、萨姆索诺夫、刘国梁、朱世赫、法尔克和莫雷加德。其组织标签分别突出衔接、反手前点、台内前三板、横打、旋转纵深、正手连续、起板转换、变化控制、风险控制、相持落点、近台抢先、削球反击、颗粒衔接或变化反击。它们是游戏设计先验，具体0—1参数不是公开采访提炼或论文测量，不能作为现实球员认证。

每项单独先验带`effective_from/effective_through`，只在对应成熟期快照采用；例如马龙2004、樊振东2012、张继科2008仍使用原年度原型，不倒灌后来成熟期设计。显式用户`style_profile`优先，不被姓名先验覆盖。未单独设计的人物仍会共享原型，不能宣称104种风格都已独立实测；唯一轴组合数与大类分布在当前`reports/comprehensive/CARD_AUDIT.json`列出。

本次审计共有34种轴组合，14位独立先验覆盖46张成熟期快照；211/370张仍归入通用“前三板抢先偏好”。这比仅继承旧原型的22种轴组合更有区分，但同质化没有被完全消除；不能用独立词条数量冒充104人的实证个体化程度。14项Card测试通过，370张卡当前43/P6/G9/CA/PA均逐值保持。

## 后台人物档案

`personality_profile`包含三类模拟写作词，分别用于交流、准备/复盘和相处方式。它的`basis`明确为`SIMULATED_NARRATIVE_DEFAULT`，表示球员化身的虚构叙述设定；不是现实私下人格的调查结论。原创角色可用`narrative_personality`显式声明1—6个短词，来源标为`USER_DECLARED_FICTION`。

公开采访证据另放`public_cues`，只有真实查阅并核实的公开资料才可添加。每条须有来源ID、URL、日期或年份、适用范围、解释限度及`VERIFIED_PUBLIC_PRIMARY_SOURCE/VERIFIED_PUBLIC_TRANSCRIPT`核实标记。只有书目、链接、日期或未读取的候选来源不足以让它进入叙述。公开表达也不能证明私下固定性格、心理诊断或某场比赛失败的真实心理原因。

本轮外部期刊和官方采访访问受网络代理拒绝，未能独立核实新的原始采访。因此104位人物的`public_cues`目前全部为空；已提供的是明确模拟默认词，而不是用户要求的采访提炼已完成。文献检索边界与待核实线索见`docs/V118_RESEARCH_ZH.md`，不能把候选书目当作已阅读证据。

## 时间、公开与叙述隔离

`public_view(card)`保留身份、年龄、国籍、器材、当前43子值/P6/G9/CA、公开PA、XP、许可、学习系数、实际模拟战绩和排名；剔除后台人格、潜在未来上限及原档案中的冠军原型标签、回溯技术宣言。

`narrative_view(card, as_of_year=..., as_of_date=...)`提供合格写作线索。已知日期按日过滤，无月日的资料保守视为当年12月31日可用；仅传年份则明确以该年年末为截点。未知日期资料不事实化，未来采访不能倒灌早年世界。实际比赛事实仍只能来自真实比赛日志；性格与风格的描写不得冒充某一分已发生的因果。

原V1.1.7的Card和数值档案未改字节。新模块是显式入口；不能将旧版本完整存档改标签后当作已迁移的新世界。
