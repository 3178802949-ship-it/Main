# 《旋球年代》赛制与成长一致性补丁：Codex实施规格 vNext（尚未实施）

## 不可违反的约束
原始V1.1.7综合版完整保留且默认不变；实验补丁为可选层。2004年所有已锁定比赛结果、对阵、G9/P6、CA、2005-01-01世界快照只读，不能重抽、改写或擅自迁移。任何修正生成2005+新分支或独立迁移预览。所有事件唯一ID、来源标记 REAL_MENS_BASELINE / SIMULATED / ESTIMATE / UNVERIFIED，历史成绩与架空比分严格分离。不存在可靠史料时不得声称官方签表。

## P0 比分松懈与反扑（LIGHT-4 anti-shutout v0.2）
仅在逐分胜率采样之前调整概率，禁止事后编辑局分。双方共用规则，不按玩家/NPC区分。建议领先方达到7分且领先≥4分才启动，修正为相对于基础概率的加法，上限绝对0.085；在7分、4分差阈值处连续渐进（避免突然跳变），结合比分、发球方、体能、竞技稳定性和已有战术执行状态。领先方的松懈判定与落后方的调整判定应是独立、可记录且可失败的随机事件，不应双重累计超过上限。不修改永久CA/G/子项，保持p在(0,1)、11:0非零可能。比分恢复接近时衰减，换局重置，10:10以后建议限制到0。保存每分 pre_p、slack_draw、comeback_draw、delta_p、post_p、seed；支持开关。设计对照组验证零封率、胜率、平均分、局长、反转率，避免鼓励故意让分。

## P0 正式比赛BO3/BO5/BO7
match format为best_of=3,5,7，分别先赢2/3/4局。单局11分且必须净胜2分；10:10以后发球次序适配，决胜局换边等赛规可配置。资格/正赛由赛事规则确定，不允许按人物名气来回切换局数。比分有效性、先赢局数及时停止、局分/总分/小组排名标准化；同组必须一致赛制；胜场→相互战绩→局分差→得失分率/分差等顺序由competition_rules明确声明，循环相互交锋采用相应多方排序，不要硬编码唯一历史规程。

## P0 统一时钟、疲劳、伤病、比赛结算
WorldState唯一权威event clock，可在日内处理多事件；timezones和真实赛事日程保存时区及local date。训练期间有比赛时按天排程，训练占用/强度与赛事互斥，无法双计。疲劳建议范围0–100，分场：基础出场负荷 + 球数/回合长度/步法跑动 + 连续比赛/旅行 - 恢复，均配置并明确封顶；睡眠休息/理疗阶段降低疲劳，低概率伤病由当前疲劳、慢性部位负荷、身体P、赛程密度影响。对同一个match_id一次提交：日期、赛果、H2H、积分分类、疲劳/伤病、XP、临时状态、角色档案、训练建议。事务失败原子回滚。支持旧世界时钟外部比赛日志的独立对账，不允许自动回填2004状态。

## P0 比赛 XP：与训练相同的正式经验池、来源异质
43个子项共用训练现有XP余额及门槛，不建立永远pending的平行永久经验。训练以目标练习稳定获取XP，比赛按每分的action/quality/risk/opponent-level/decisive contribution记录，技术频繁运用获得少量熟练XP、成功高质量关键得分有小幅奖励、遇到强手并成功解决不利对位有很低概率D100突破；失误多不自动获奖励。建议XP_event = min(per_subskill_cap, base*sqrt(valid_actions)*quality_factor*challenge_factor + success_bonus + exceptional_bonus)，先校准不超过相同时间训练XP的一定比例（候选每场单项≤对应一个半月正常训练目标项收益的10–25%，需蒙特卡洛验证），整场总XP也封顶。针对动作实际使用而不是笼统把CA变成长增益。详细引擎直接用逐板事件；LIGHT聚合估算的XP应更保守，并标记approximate。训练中明确表现不足的subskills进入诊断清单：高失分关联、判别可信度、优先建议训练，不直接授予G或经验；NPC和玩家均适用。
每场结算产生MatchSettlement(match_id, receipt_hash, worldline_id, date, subskill_deltas, xp_before_after, source, fatigue_delta, injuries, ledger_deltas, h2h_deltas, rank_deltas, CA_before_after, original_receipt)；唯一键(worldline_id,match_id) + receipt_hash防冲突，重复提交同收据返回already_applied，冲突不同hash报错。经验累积至既有正式训练管，达到门槛按原版成长规则升级，CA只能从子项/P6的权威函数计算，不能另手填。2004年既有pending使用量/波兰连胜奖励/雅典2研究凭证做迁移预览及核对表；不允许默认兑换也不允许清零，必须征得用户决定是否采用迁移分支。积分青年与成年分账，官方排名与自定义内部积分分开。

## P1 概率/竞技平衡
CA只是综合摘要，不可直接决定单分赢家；让43个G子项、P6、发球-接发、台内、正反手-步法、战术阅读、稳定性和临场波动共同决定。分层测试CA差0、±5、±10、±15、±20，至少1000场/配置，含相同CA不同战术、削球对攻、左右手、主客场、不同体能疲劳；检查胜率斜率、11:0/11:1、局平均分、逆转次数、对手均值，合理输出置信区间与校准报告，不可凭印象强制目标。已锁定2004赛果不可重算覆盖。

## P1 历史签位与人物持久库
优先读取历史真实参赛名录→资格/正赛身份→已知原始组别→成绩/晋级路线→入围和种子机制；保留证据来源和confidence。玩家应按seed随机替换同资格层级低位选手，不替换已确认种子/高轮晋级者；加入之后玩家可真实击败历史晋级者并建立alternative branch，不应“历史保护”到剥夺玩家胜利。部分历史分组缺失则生成明确标记 hypothetical 的低位小组，不能虚称复原。历史球员唯一ID+年份快照，首次完整卡锁定并逐月/季度增量更新，不能每见一次重roll。

## 发布准则
先生成engine_map、diff、迁移dry-run、回归结果、可复现命令和SHA256 manifest；测试同seed复现、同receipt二次执行无重复XP/疲劳/H2H、事务故障回滚、比赛长度规则、1月已有历史数据不变、2005新分支可运行、关闭所有补丁时与原版输出一致。至少1000场/每参数组合；端到端复测全年23场原始比赛原样保留；禁止声称未完成测试通过。原版只读，补丁开关默认off，给出rollback说明。
